# Приватний Будівельний Калькулятор

Офлайн-калькулятор будівельних кошторисів: окремо роботи і матеріали, власний прайс,
категорії, архів кошторисів, друк і експорт у PDF.

Застосунок не потребує ні сервера, ні збірки, ні інтернету — достатньо відкрити
`index.html` у браузері.

## Запуск

```
Відкрийте index.html подвійним кліком.
```

Це працює з протоколу `file://`, бо код підключено класичними `<script src>` без
ES-модулів. Якщо перевести проєкт на `import`/`export`, браузер заблокує
завантаження модулів через CORS і застосунок перестане відкриватися без сервера.

За бажанням можна підняти локальний сервер:

```bash
npx serve .
```

## Можливості

- **Розрахунок робіт і матеріалів** — введіть обсяг напроти позиції, суми рядка й
  загальні підсумки перераховуються миттєво.
- **Власна база прайсів** — категорії, позиції (назва, одиниця, ціна), зміна порядку
  рядків кнопками `▲` `▼`.
- **Архів кошторисів** — збережений кошторис фіксує ціни на момент збереження, тому
  подальші зміни прайсу його не спотворюють.
- **Друк / Зберегти як PDF** — документ на A4 із шапкою об'єкта, повтореною шапкою
  таблиці на кожній сторінці та рядками для підписів.
- **Завантажити PDF** — справжній `.pdf` файл одним кліком, з кириличним шрифтом.
- **Резервна копія** — експорт та імпорт усієї бази у JSON для перенесення на інший
  пристрій.

## Два способи отримати PDF

| Кнопка | Як працює | Коли зручніше |
| --- | --- | --- |
| `🖨️ Друк / Зберегти як PDF` | Системний діалог друку браузера, стилі з `css/print.css` | Швидко, є попередній перегляд сторінок, можна вибрати принтер |
| `📄 Завантажити PDF` | Генерація файлу через jsPDF + autoTable | Одразу готовий файл із передбачуваним іменем, без діалогів |

Обидва працюють офлайн. Обидві кнопки також доступні для кожного запису в архіві
кошторисів.

## Структура

```
index.html                 розмітка і підключення ресурсів
css/
  base.css                 скидання, фон, типографіка
  layout.css               контейнер, шапка, вкладки, панель керування
  components.css           картки, таблиці, форми, кнопки, модальне вікно
  print.css                @media print — документ кошторису на A4
js/
  utils.js                 escapeHtml, форматування чисел і дат, імена файлів
  config.js                ключ сховища, типова база, налаштування PDF
  store.js                 стан застосунку + localStorage
  catalog.js               операції над категоріями і позиціями прайсу
  estimate.js              підсумки поточного кошторису, архів
  estimate-doc.js          спільна модель документа для перегляду, друку і PDF
  render.js                рендер усіх екранів
  preview.js               модальне вікно + HTML-рендер документа
  export-json.js           резервна копія бази
  export-print.js          друк
  export-pdf.js            генерація PDF
  app.js                   обробники інтерфейсу, ініціалізація
vendor/                    локальні копії бібліотек і шрифтів
```

Порядок підключення скриптів у `index.html` має значення: `vendor/` завантажується
першим (autoTable підключається до вже наявного jsPDF, шрифти реєструються в
`jsPDF.API`), далі модулі застосунку від `utils.js` до `app.js`.

## Дані і резервні копії

База зберігається у `localStorage` браузера під ключем `build_calc_db`. Це означає:

- дані прив'язані до конкретного браузера й способу відкриття (`file://` і сайт на
  хостингу мають окремі сховища);
- очищення даних сайту в браузері **безповоротно стирає прайс і архів**;
- обсяг сховища обмежений приблизно 5 МБ.

Тому регулярно робіть `📥 Експорт бази (.json)` — це єдиний спосіб відновити прайс.

Обсяги, введені в калькуляторі, зберігаються лише в пам'яті сторінки: після
перезавантаження їх треба ввести знову. Щоб зафіксувати роботу, збережіть кошторис
у архів.

## Оновлення вендорених бібліотек

Рантайм-залежностей немає, `vendor/` містить готові файли. Щоб їх оновити:

```bash
npm pack jspdf@4.2.1 jspdf-autotable@5.0.8 @expo-google-fonts/roboto@0.4.3
```

- `jspdf/dist/jspdf.umd.min.js` → `vendor/jspdf.umd.min.js`
- `jspdf-autotable/dist/jspdf.plugin.autotable.min.js` → `vendor/jspdf.plugin.autotable.min.js`
- `Roboto_400Regular.ttf` і `Roboto_700Bold.ttf` → base64 у `vendor/fonts/roboto-normal.js`
  і `vendor/fonts/roboto-bold.js`

Шрифт потрібен тому, що 14 стандартних шрифтів PDF обмежені ASCII і не містять
кирилиці. Обидва стилі (`normal` і `bold`) обов'язкові: якщо зареєструвати лише
`normal`, jsPDF при `setFont('Roboto', 'bold')` тихо підставить helvetica і
український текст зламається.
